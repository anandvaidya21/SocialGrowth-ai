# 🚀 SocialGrowth-AI

SocialGrowth-AI is an AI-powered project designed to help users grow their social media presence using intelligent content analysis and strategy generation.

## 📌 Project Status

⚠️ This project is currently in the **early development phase**.
Basic structure has been created with a minimal frontend and backend logic.

---

## 🧠 Tech Stack

* **Backend:** Python, FastAPI
* **NLP:** spaCy
* **Data Validation:** Pydantic (BaseModel)
* **Frontend:** Basic Python UI (Streamlit/app.py)
* **API Framework:** FastAPI

---

## 🎯 Features (Current)

* Basic backend API setup using FastAPI
* Initial NLP integration using spaCy
* Simple frontend interface
* Strategy and content analysis (basic logic)

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/anandvaidya21/SocialGrowth-ai.git
cd SocialGrowth-ai
```

2. Create virtual environment:

```
python -m venv venv
venv\Scripts\activate
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run backend server:

```
uvicorn backend.main:app --reload
```

5. Run frontend:

```
streamlit run app.py
```
